---
title: Shopify DevTools
description: Inspect live store metadata and authentication status during development.
---

Run your app in development, open it inside Shopify admin, then open Nuxt DevTools and select the **Shopify** tab. The integration uses DevTools v3's custom iframe tab API; the playground pins DevTools to 3.4.4 for Shopify CLI compatibility.

The inspector displays:

- Store name, myshopify domain, currency, and storefront URL.
- Installed scopes returned by Shopify and configured requested scopes.
- Admin API version, app URL, and distribution.
- Online/offline token mode, access/refresh expiry dates, and whether refresh credentials are present.

Select **Refresh store** to make a new authenticated, read-only Admin API request. Expiring offline sessions use the module's normal renewal lifecycle. The inspector never returns access tokens, refresh tokens, API secrets, session state, or the complete runtime configuration.

## Authentication and availability

The tab's page and API endpoint are registered only when `nuxt.options.dev` is enabled. The endpoint also rejects non-development requests and sends `Cache-Control: no-store`.

The iframe obtains an ID token from an authenticated App Bridge instance in a same-origin ancestor app window. It does not accept shop names or credentials entered into a form, enumerate stored sessions, or expose store data to anonymous requests. Open the app through Shopify admin; a standalone localhost tab does not have the required identity context. An inaccessible ancestor frame produces an explanatory connection error rather than bypassing authentication.

The default tab URL is `/_shopify/devtools`; its authenticated data endpoint is `/_shopify/devtools/store`. Both paths are reserved for this development integration.

For Nuxt's current v4 integration API, see the [module authors guide](https://nuxt.com/modules/devtools/module-authors). This module deliberately uses the pinned v3 API instead of enabling v4.
