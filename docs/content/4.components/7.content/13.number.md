## Props

| Prop | Type | Polaris default |
| --- | --- | --- |
| `accessibilityVisibility` | `'visible' \| 'hidden' \| 'exclusive'` | `'visible'` |
| `color` | `'base' \| 'subdued'` | `'base'` |
| `dir` | `'' \| 'auto' \| 'ltr' \| 'rtl'` | `''` |
| `fontSize` | `'small-200' \| 'small-100' \| 'small' \| 'base' \| 'large' \| 'large-100' \| 'auto'` | `'auto'` |
| `fontWeight` | `'base' \| 'auto' \| 'medium' \| 'semibold' \| 'bold'` | `'auto'` |
| `tone` | `'auto' \| 'neutral' \| 'info' \| 'success' \| 'caution' \| 'warning' \| 'critical'` | `'auto'` |

## Slots

| Slot | Description |
| --- | --- |
| `default` | Numeric text to display with tabular numerals. |

Number does not format, round, or localize its content. Format values in your application before rendering. Unlike `ShNumberField`, it is not an editable form control.

## Polaris Element

Renders as `<s-number>`. See [Shopify Number reference](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/number).
