## Props

| Prop   | Type                                                              | Default | Description      |
| ------ | ----------------------------------------------------------------- | ------- | ---------------- |
| `src`  | `string`                                                          | —       | Image source URL |
| `alt`  | `string`                                                          | —       | Alt text         |
| `size` | `'small' \| 'small-100' \| 'small-200' \| 'base' \| 'large' \| 'large-100'` | — | Thumbnail size |

## Slots

The `loading` prop accepts `'eager'` (Polaris default) or `'lazy'`. Use `loading="lazy"` to defer requesting images until they are shown, such as thumbnails in a closed menu.

| Slot      | Description           |
| --------- | --------------------- |
| `default` | Additional content    |

## Polaris Element

Renders as `<s-thumbnail>`. See [Polaris Thumbnail docs](https://shopify.dev/docs/api/app-home/web-components/content/thumbnail).
