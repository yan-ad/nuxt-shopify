---
title: LoadingIndicator
description: Bridges Nuxt loading indicator with Shopify Admin loading bar.
---

## Live preview

This component integrates with Shopify App Bridge and requires an authenticated Shopify admin host. It cannot run faithfully in a standalone documentation iframe. Use the [authenticated playground](https://github.com/yan-ad/nuxt-shopify/tree/main/playground) to try it with your development store.

## Usage

Wrap your page or layout content:

```vue
<template>
  <ShLoadingIndicator>
    <ShPage title="Products">
      <!-- content -->
    </ShPage>
  </ShLoadingIndicator>
</template>
```

## Props

This component has no props.

## Slots

| Slot      | Description      |
| --------- | ---------------- |
| `default` | Page content     |

## Notes

- Uses `useLoadingIndicator()` from Nuxt to watch the `isLoading` state.
- Calls `shopify.loading.show()` / `shopify.loading.hide()` via `useAppBridge()`.
- Automatically hides the loading bar on component unmount.
- This is a renderless component — it does not produce any wrapper DOM element.
