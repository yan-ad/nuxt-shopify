## Props

Includes all [Box](/components/layout/box) props plus:

| Prop         | Type     | Default | Description       |
| ------------ | -------- | ------- | ----------------- |
| `gridColumn` | `string` | —       | Grid column value |
| `gridRow`    | `string` | —       | Grid row value    |

## Slots

| Slot      | Description        |
| --------- | ------------------ |
| `default` | Grid item content  |

## Polaris Element

Renders as `<s-grid-item>`. See [Polaris Grid docs](https://shopify.dev/docs/api/app-home/web-components/layout/grid).
