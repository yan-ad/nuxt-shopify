## Props

| Prop | Type | Description |
| --- | --- | --- |
| `heading` | `string` | Plain-text heading explaining the empty state. |

## Slots

Use the default Vue slot with native `slot` attributes on its children. This keeps the slotted components directly under `<s-empty-state>` without adding wrappers.

| Child's `slot` attribute | Accepted content |
| --- | --- |
| `graphic` | One `ShIcon` or `ShImage`. |
| `subheading` | `ShText` and `ShLink` supporting content. |
| `primary-action` | One `ShButton` with `variant="primary"`. |
| `secondary-actions` | One `ShButton` with `variant="secondary"` or `"auto"`, despite the plural slot name. |

Unsupported children are ignored by Polaris with a development warning. Outside a table, render the empty state conditionally when your data is empty. Inside `ShTableBody`, the table shows it when there are no rows and the table is not loading.

## Polaris Element

Renders as `<s-empty-state>`. See [Shopify Empty state reference](https://shopify.dev/docs/api/app-home/latest/web-components/feedback-and-status-indicators/empty-state).
