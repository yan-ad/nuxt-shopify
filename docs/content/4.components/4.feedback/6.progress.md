## Usage

```vue
<template>
  <ShProgress accessibility-label="Order fulfillment" :value="3" :max="5" tone="info" />
  <ShProgress accessibility-label="Importing products" />
</template>
```

## Props

| Prop | Type | Polaris default | Description |
| --- | --- | --- | --- |
| `accessibilityLabel` | `string` | — | Accessible name describing what is progressing. Always supply a meaningful label. |
| `max` | `number` | `1` | Total work; must be greater than zero. |
| `value` | `number` | Unset / indeterminate | Completed work between zero and `max`. Omit for indeterminate progress. |
| `tone` | `'auto' \| 'neutral' \| 'info' \| 'success' \| 'caution' \| 'warning' \| 'critical'` | `'auto'` | Semantic meaning and color. |

The wrapper does not assign a default value, preserving Polaris's indeterminate mode. Progress is display-only: it has no `v-model`, input events, or text slots. Add adjacent `ShText` when you need a visible label or count.

## Polaris Element

Renders as `<s-progress>`. See [Shopify Progress reference](https://shopify.dev/docs/api/app-home/latest/web-components/feedback-and-status-indicators/progress).
